# AgroShield AI

## Project Objective

AI-powered crop disease detection system that analyzes leaf images and identifies crop diseases.

## Crops

1. Tomato
2. Potato
3. Corn

## Classes

1. Tomato Healthy
2. Tomato Early Blight
3. Tomato Late Blight
4. Potato Healthy
5. Potato Early Blight
6. Potato Late Blight
7. Corn Healthy
8. Corn Common Rust
9. Corn Gray Leaf Spot

## Input

Leaf image

## Output

- Crop name
- Disease name
- Confidence score
- Disease information
- Basic recommendation
